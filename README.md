## 📌 Overview

**Demand Forecasting & Inventory Optimization** is an end-to-end Data Science and Machine Learning project designed to forecast future product demand and support data-driven inventory planning.

The project analyzes historical sales data, performs data preprocessing and feature engineering, trains machine learning models for demand prediction, and provides inventory optimization insights such as recommended stock levels and replenishment decisions.

## 🎯 Objectives

* Forecast future product demand using historical sales data.
* Identify important patterns and trends affecting demand.
* Build and evaluate machine learning models for forecasting.
* Reduce the risk of **stockouts and overstocking**.
* Support data-driven inventory and replenishment decisions.
* Provide an interactive interface for forecasting and inventory insights.

## ✨ Key Features

* 📊 Exploratory Data Analysis and visualization
* 🧹 Data cleaning and preprocessing
* ⚙️ Feature engineering for demand forecasting
* 🤖 Machine Learning-based demand prediction
* 📈 Model evaluation using forecasting metrics
* 📦 Inventory optimization and stock recommendations
* 🗄️ SQL-based business and data analysis
* 📋 Interactive forecasting and inventory dashboard

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/sayalivadya1654-cell/Demand-Forecasting-Inventory-Optimization.git
cd Demand-Forecasting-Inventory-Optimization
```

### 2. Create a virtual environment

**Windows:**

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Usage

### Run the notebooks

Open the project in Jupyter Notebook or VS Code and execute the notebooks in order for data analysis, preprocessing, feature engineering, model training, and evaluation.

### Run the application

After installing the dependencies:

```bash
streamlit run app/app.py
```

The application provides an interactive interface for demand forecasting and inventory-related insights.

## 📊 Model Evaluation

The forecasting models are evaluated using appropriate regression and forecasting metrics such as:

* **MAE** — Mean Absolute Error
* **MSE** — Mean Squared Error
* **RMSE** — Root Mean Squared Error
* **R² Score** — Coefficient of Determination

Model performance is compared to identify the most suitable model for demand prediction.
